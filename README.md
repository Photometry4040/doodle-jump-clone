# Doodle Jump Clone

Python과 Pygame으로 제작한 Doodle Jump 클론 게임입니다.

## 버전 정보
- v1.0.0: 기본 게임 메커니즘 구현
- v1.0.1: 플랫폼 충돌 감지 및 스크롤링 시스템 개선

## 게임 설명
- 좌우 방향키로 캐릭터를 조작합니다
- 플랫폼에 착지하면 자동으로 점프합니다
- 화면 밖으로 떨어지면 게임이 종료됩니다
- 높이 올라갈수록 점수가 올라갑니다

## 실행 방법
1. 로컬에서 실행하기
```python
# 필요한 패키지 설치
pip install pygame

# 게임 실행
python main.py
```

2. 웹에서 플레이하기
- [게임 플레이하기](https://photometry4040.github.io/doodle-jump-clone)

## 기술 스택
- Python 3.11
- Pygame
- Pygbag (웹 배포용)
